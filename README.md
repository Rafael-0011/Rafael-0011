# Rafael Chaves

**Backend Engineer · Java & Spring Boot**

Desenvolvedor backend com experiência em sistemas corporativos de alta criticidade — desde APIs REST e microsserviços até integração com mensageria (Kafka), armazenamento de objetos (MinIO/S3) e pipelines de CI/CD.

Atuei em ambientes que exigem confiabilidade, rastreabilidade e performance: saúde pública (SESA/CE) e produtos SaaS B2B. Entrego código limpo, testável e documentado — não só funcional.

---

## 🏆 Impactos recentes

- **SESA-CE**: corrigi inconsistências em relatórios e auditorias de sistemas de saúde pública, reduzindo erros operacionais em módulos críticos usados por hospitais
- **Colmeia Tecnologia**: implementei integração com MinIO (S3-compatible) para gestão de arquivos com controle de acesso via API; contribuí com automação de processos e relatórios gerenciais via JasperReports
- Trabalhei em squads ágeis (Scrum/Kanban) com code review e foco em estabilidade contínua de sistemas
